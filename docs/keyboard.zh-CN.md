# 键盘快捷键

[English](./keyboard.md) · **中文**

---

预览打开后，焦点自动锁定在遮罩层上，以下快捷键立即生效。

在 **`presentation="contained"`** 下，仅当焦点位于预览根子树内时处理快捷键（点击预览可激活）；侧栏操作时不会吞方向键 / Esc。

> 当缩放比例输入框处于编辑状态时，方向键和空格不触发全局快捷键，由输入框自行处理。

## 缩放

| 按键 | 功能 |
|------|------|
| `+` / `=` / `↑` | 放大（跳到下一个较大档位） |
| `-` / `↓` | 缩小（跳到下一个较小档位） |
| `0` | 切换到适应（Fit）模式 |
| `1` | 切换到原始比例（100%） |
| `Space` | 在适应 ↔ 100% 之间切换（与双击效果相同） |

> 缩放比例输入框可输入正整数，提交时会**限制在当前 `stops` 的最大值**（默认最高 200%），按 **Enter** 确认，**Esc** 取消。

## 图片导航

| 按键 | 功能 |
|------|------|
| `←` | 扁平列表上一张（有 `groupedImages` 时会跨组） |
| `→` | 扁平列表下一张（有 `groupedImages` 时会跨组） |
| `PageUp` | 跳到上一组第一张（需非空 `groupedImages`） |
| `PageDown` | 跳到下一组第一张（需非空 `groupedImages`） |

## 平移

| 按键 | 功能 |
|------|------|
| `Ctrl / ⌘` + `方向键` | 向对应方向平移视野，每次移动视口较短边的 15% |
| `Shift` + `方向键` | 由 `shiftArrowAction` 决定；默认同上 |

> 箭头表示希望查看的方向。例如按 `Ctrl / ⌘` + `→` 会显示图片右侧内容。方向状态严格跟随当前实际按下的按键：两个互相垂直的方向键组合成 45° 斜向平移，松开其中一个后立即恢复为剩余的单方向；相反方向同时按下时在对应轴上抵消。斜向步长会归一化以保持总速度一致。仅原始比例（Native）模式支持平移；到达边界后不会继续移动。

> **macOS 限制：**部分浏览器在 `Command` 保持按下时可能不派发方向键的 `keyup`，网页因而无法可靠获知真实松开状态。需要严格、连续的游戏式八方向输入时，请保持默认的 `shiftArrowAction="pan"` 并使用右侧 `Shift + 方向键`；Windows/Linux 的 `Ctrl + 方向键` 不受这项 macOS 限制影响。

当 `shiftArrowAction="rotate"` 时，`Shift + ←` 逆时针旋转 90°，`Shift + →` 顺时针旋转 90°；`Shift + ↑/↓` 仍执行普通的放大/缩小。工具栏旋转始终可用。

## 关闭

| 按键 | 功能 |
|------|------|
| `Esc` | 关闭预览 |

---

> 任意按键操作均会重置控件自动渐隐计时器，立即将所有控件恢复为完全可见状态。
